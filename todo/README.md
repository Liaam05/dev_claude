# Todo App

シンプルなバニラJS製のTodoアプリです。フレームワーク不使用、単一ページで動作します。

## ファイル構成

```
todo/
├── index.html   # HTMLマークアップ
├── style.css    # スタイル（CSS変数・テーマ・レスポンシブ）
└── script.js    # ロジック（状態管理・レンダリング・イベント）
```

## 機能

- タスクの追加・編集（ダブルクリック）・削除
- 優先度（高/中/低）と期限日の設定
- フィルター（すべて / 未完了 / 完了済み）
- 並び替え（手動 / 優先度順 / 期限順 / 作成順）
- ドラッグ&ドロップによる手動並び替え
- ライト/ダークテーマ切り替え
- `localStorage` によるデータ永続化

## 使い方

`index.html` をブラウザで直接開くだけで動作します。サーバー不要です。
